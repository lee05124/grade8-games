# 單字生活線

國中英文單字與片語練習遊戲，打開網頁就能玩，不需要登入。

- 會考路線：早餐店、教室、圖書館、夜市、捷運站、診所 6 站情境對話，共 42 個單字片語，單字都在會考常用 2000 字範圍內
- 我的單字：貼上課本的單字表（`英文, 中文, 例句`）和佳句（`英文 | 中文 | 文法說明`），就能練選擇題、拼字和句子重組
- 錯題本：答錯的字依 1、2、4、7 天的間隔安排複習，連續答對 3 次就移出
- 等級與徽章：答題累積 XP 升級，達成條件拿徽章
- 家長報表：近 14 天練習量、答對率、待加強的字，可以複製成文字貼到 LINE
- 發音：使用裝置內建的英文語音，每句對話、單字和佳句都能點來聽

## 使用前要知道

- 進度存在這台裝置的瀏覽器裡。換裝置、用無痕視窗或清除瀏覽資料，進度就不會跟著。
- AI 自由對話、AI 出閱讀題這兩個功能需要 Claude，這個網址版本沒有。
- 課本內容沒有放在這裡。因為著作權，出版社課本的課文、單字表和佳句不收錄，請自己在「我的單字」輸入。

## 修改

整個遊戲只有 `index.html` 一個檔案。要修改會考路線的題目，編輯檔案裡的 `SCENES` 清單。
